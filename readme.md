## ✨ 4. 주요 기능 (Main Features)

- **상황 기반 무드 입력**
    - 지금 상황을 자유 텍스트로 입력 (최대 200자)
    - '듣고 싶은 가수'·'듣고 싶은 장르'로 추천 범위 지정
    - 추천 무드 칩(🏃 러닝, 🌙 새벽 감성, ☕ 카페, 🌸 봄 산책, 💫 힐링)으로 빠른 입력
- **무드 맞춤 음악 추천**
    - 입력한 무드에 어울리는 곡을 2×2 앨범 그리드로 제공
    - 카드 탭으로 재생/일시정지, 재생 중 비주얼라이저 애니메이션
    - 추천 결과를 플레이리스트로 저장
- **음악 감상 기록 (캘린더)**
    - 날짜별로 그날 들은 곡을 시간순 타임라인으로 기록
    - 곡마다 감상 당시의 무드 태그 표시
    - 하루 여러 번의 감상 흐름을 한눈에 확인

## 📌 6. Git 브랜치 전략 및 컨벤션

### 🌳 Branch Strategy

- **main**: 제품 출시 및 배포 버전을 관리하는 브랜치
- **develop**: 개발 브랜치, 기능 개발 완료 후 병합
- **feature/**: 개별 기능 개발을 위한 브랜치 (예: `feature/mood-input`)

### 💬 Commit Convention

- **feat**: 새로운 기능 추가
- **fix**: 버그 수정
- **docs**: 문서 수정 (README 등)
- **refactor**: 코드 리팩토링
- **style**: 스타일 수정 (포맷팅, 세미콜론 등)
